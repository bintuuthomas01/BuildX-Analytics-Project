# 📊 BuildX Analytics Project – College Placement Analysis

## 📌 Project Overview

This project was completed as part of the **BuildX Data Analytics Bootcamp**. The objective was to perform an end-to-end data analytics workflow using real-world placement data. The project covers data cleaning, SQL-based business analysis and Power BI dashboard creation

The goal is to analyze the factors that influence student placements and salaries, and to present meaningful insights that can help educational institutions and placement cells improve student outcomes.

---

# 🎯 Objectives

- Clean and prepare raw placement data using Python.
- Perform business analysis using SQL queries.
- Build an interactive Power BI dashboard.
- Generate insights from the data.
- Publish the complete project on GitHub as a professional portfolio.

---

# 📂 Dataset

**Dataset Name:** `placement.csv`

The dataset contains information about students, including:

- Student ID
- Gender
- Secondary School Percentage
- Higher Secondary Percentage
- Degree Percentage
- Degree Type
- Work Experience
- Employability Test Score
- MBA Percentage
- Specialisation
- Placement Status
- Salary

# 🐍 Part 1 – Data Cleaning & Preparation (Python)

The dataset was cleaned using Python and Pandas.

### Tasks Performed

- Loaded the dataset using Pandas
- Displayed the first five rows
- Checked for missing values
- Filled missing salary values
- Removed duplicate records
- Cleaned text columns
- Verified and corrected data types
- Renamed columns for consistency
- Created a new calculated column
- Exported the cleaned dataset

### Output File

- `cleaned_dataset.csv`

---

# 🗄️ Part 2 – Business Analysis (SQL)

The cleaned dataset was imported into SQLite for business analysis.

### SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- BETWEEN
- Aggregate Functions
- Advanced Analytical Queries

### Business Questions Answered

- Which students were successfully placed?
- What is the average salary for each specialisation?
- Which students received the highest salaries?
- Which degree types have the most students?
- Which students scored high MBA percentages?
- How do placement status and salary compare across degree types?

---

# 📌 Key Insights

Some important insights obtained from the dashboard include:

- Students with work experience generally received higher salaries.
- Certain specialisations achieved higher placement rates than others.
- Average salary varied across different degree types.
- Employability test scores showed a positive relationship with placement outcomes.
- MBA percentage and degree performance contributed to better placement opportunities.
